# Brand Assets

`SolaceLogo.png` is the supplied logo preview. It is only 120×120 pixels, so replace it with the approved high-resolution square source (ideally 1024×1024 or larger) before generating launcher icons.

The same source path is configured for Android, iOS, web, Windows, and macOS in `pubspec.yaml`. After replacing the file, run `dart run flutter_launcher_icons`. Keep important artwork within the center safe area so platform icon masks do not crop it. Add a separate wordmark file if the design includes a horizontal logo for use inside the app.
